기존 기상청 프로젝트는 Docker(Airflow) → FastAPI → React 순서로 작동합니다.
1. Docker와 Airflow 켜기
먼저 Docker Desktop을 실행하고, PowerShell에서 아래 명령어를 입력.
cd C:\Users\AISW_203_115\Desktop\airflow
docker compose up -d


실행 상태 확인:
docker compose ps


컨테이너가 Up 또는 healthy 상태인지 확인.
Airflow 주소: http://localhost:8082
2. FastAPI 켜기
PowerShell 창을 새로 하나 열고 아래 명령어를 실행.
conda activate weather
cd C:\Users\AISW_203_115\Desktop\weather-data-pipeline
uvicorn api.main:app --reload --port 8002


정상 실행되면 다음 주소에서 API를 확인.
- API 문서: http://localhost:8002/docs
- 기상 데이터 API: http://localhost:8002/api/weather
- 파이프라인 실행 이력: http://localhost:8002/api/pipeline/runs
3. React 대시보드 켜기
PowerShell 창을 하나 더 열고 다음 명령어를 실행.
cd C:\Users\AISW_203_115\Desktop\weather-data-pipeline\frontend
npm run dev


터미널에 표시되는 주소로 접속.
http://localhost:5173
